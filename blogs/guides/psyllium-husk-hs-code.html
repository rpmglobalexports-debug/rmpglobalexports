Psyllium Husk HS Code: Understanding HSN, HTSUS, and Import Classification

If you're importing psyllium husk from India, using the correct product classification is just as important as agreeing on specifications and pricing. Buyers often encounter confusion between the international six-digit HS code, India's eight-digit HSN code, and country-specific classifications such as the US HTSUS or the EU TARIC system.

This guide explains how psyllium husk is classified, why different countries use different code extensions, and what importers should verify before finalizing a purchase order.

The International HS Code for Psyllium Husk

Psyllium husk falls under HS heading 1211, which covers:

"Plants and parts of plants (including seeds and fruits), of a kind used primarily in perfumery, pharmacy, or for insecticidal, fungicidal, or similar purposes."

The first six digits of the Harmonized System (HS) are standardized internationally. This means that the six-digit classification is recognized across most countries.

For psyllium husk, the key classification starts with:

  • HS heading: 1211
  • International six-digit HS code: 1211.90

However, the classification process does not stop at six digits. Most countries add additional digits for their own customs and tariff systems.

What Is the Difference Between HS Code and HSN Code?

Buyers frequently use the terms "HS code" and "HSN code" interchangeably, but they serve slightly different purposes.

Classification system Number of digits Used by
HS code 6 digits International trade
HSN code (India) 8 digits Indian customs and exports
HTSUS (United States) 10 digits US imports
TARIC (European Union) Extended code EU imports

The first six digits remain standardized internationally. Additional digits are country-specific and may affect customs procedures and duty calculations.

Psyllium Husk HSN Code in India

For exports from India, psyllium husk is commonly classified under:

  • Indian HSN code: 12119032

Indian exporters use this eight-digit code in export documentation, commercial invoices, shipping bills, and customs filings.

International buyers sourcing psyllium husk from India should ensure that the HSN code shown on export documents matches the product description in the purchase order. Why Destination Countries Use Different Codes

Although the first six digits are internationally harmonized, importing countries extend the code to meet their own customs requirements.

United States (HTSUS)

US customs uses the Harmonized Tariff Schedule of the United States (HTSUS), which extends the code to ten digits. Examples sometimes used for psyllium-related imports include:

  • 1211.90.9120
  • 1211.90.9131

European Union (TARIC)

The European Union uses the TARIC system, which extends the six-digit HS code for customs and tariff purposes. For buyers importing psyllium husk into EU member states, the final classification may depend on factors such as:

  • Product form
  • Degree of processing
  • Intended use
  • Packaging
  • Supporting documentation

Important: Buyers should always confirm the exact TARIC classification with their customs broker before shipment. For a full documentation and supplier verification guide covering Germany specifically, see our psyllium husk importer Germany guide.

Why Using the Wrong HS Code Causes Problems

Incorrect product classification can create problems for both buyers and suppliers.

Customs Delays

If customs authorities determine that the declared code does not match the actual product, shipments may be held for additional inspection. This can lead to:

  • Port delays
  • Additional documentation requests
  • Storage charges
  • Missed delivery schedules

Incorrect Duty Calculations

Different classifications may carry different duty treatments. Using the wrong code can result in:

  • Underpayment of duties
  • Overpayment of duties
  • Customs reassessments

Importers should always verify duty implications with their customs broker rather than relying solely on online trade databases.

Compliance and Litigation Risk

Incorrect classification may expose importers to compliance disputes, customs penalties, or legal challenges. As a general trade-compliance principle, procurement teams should treat product classification as a customs matter rather than simply copying a code from a previous shipment or a trade-data website.

Psyllium Husk Import Classification Checklist

Before placing a purchase order, buyers should confirm the following:

  • ✓ The supplier's export documents use the correct Indian HSN code (12119032).
  • ✓ The customs broker has confirmed the destination country's classification.
  • ✓ The commercial invoice description matches the HS code.
  • ✓ The packing list and shipping documents use the same classification.
  • ✓ Any country-specific requirements have been reviewed.
  • ✓ The duty treatment has been verified independently.

Common Mistakes Buyers Make

Copying Codes From Trade Databases

Trade-data websites can be useful references, but they do not replace customs advice. A code used by one importer may not apply to another shipment if the product specifications differ.

Assuming the Indian HSN Code Applies Everywhere

India's eight-digit HSN code is designed for Indian customs procedures. US, EU, and other markets use their own extended classifications.

Finalizing a Purchase Order Before Confirming Classification

Buyers should confirm product classification with their customs broker before issuing a purchase order or opening a letter of credit. Changing the classification after shipment can create delays and additional costs.

Documents Buyers Should Cross-Check Against the HS Code

The product classification should remain consistent across all export documents, including:

  • Commercial invoice
  • Packing list
  • Certificate of origin
  • Third-party NABL laboratory COA
  • Phytosanitary certificate
  • Fumigation certificate
  • Shipping bill

Any discrepancy between these documents can trigger customs queries. For a detailed breakdown of the documentation required for psyllium husk imports, see our Germany import guide, which covers each document type in depth.

Key Takeaways

For international buyers sourcing psyllium husk from India, remember these points:

  • The international HS heading is 1211.
  • India's eight-digit HSN code for psyllium husk is 12119032.
  • Countries such as the US and EU use their own extended classifications.
  • The wrong code can result in customs delays, duty errors, and compliance issues.
  • Always confirm the final classification with your customs broker before shipment.
